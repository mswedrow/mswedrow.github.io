Welcome! This branch contains my CTF writeups, which I use to learn about various vulnerabilities. 
All writeups are from "retired" systems on Hack The Box, which means that writeups are allowed to be posted.
I do my best to show the exact steps on how to exploit the box, so feel free to follow along if you have an account!
Each writeup will also explain the vulnerability, why it can be exploited, and how it can be prevented in real-life.
Thanks for reading and happy hacking!
